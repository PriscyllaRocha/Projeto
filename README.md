Pacotes de segurança a serem implementados

HTTPS para impedir interceptação

JWT pra autenticação, verificar quem é o usuário que ta requisitando um DELETE por exemplo

O CORS pra permitir o acesso de domínios específicos à API.

Rate Limiting pra impedir DDoS

Sanitização pra impedir SQL Injection

Logs pra atividade no servidor

Backup regular do banco
